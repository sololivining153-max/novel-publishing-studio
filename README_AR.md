# NOVEL FORGE AI — النسخة التجريبية الموحّدة

هذه حزمة مصدرية موحّدة وليست ملف APK جاهزاً للتثبيت.

## ما تتضمنه
- تطبيق Flutter أساسي لإدارة مشاريع الروايات.
- Story Architect لإنشاء مخطط الرواية عبر واجهة OpenAI على الخادم.
- Story Intelligence لإدارة الشخصيات والعلاقات وحقائق Canon والأحداث وملخصات الفصول وقرارات الكاتب.
- Novel Writer لبناء سياق المشهد وفحص استمرارية المسودة وتجهيز تعليمات الكتابة.
- Literary Editor لثمانية أنماط مراجعة، والفحوص المحلية ومقارنة نسخ النص.
- أساس دعم العربية والإنجليزية والفرنسية.

## التشغيل
1. انسخ `.env.example` إلى `.env` وضع `OPENAI_API_KEY` في الخادم فقط.
2. شغّل `docker compose up --build`.
3. افتح `http://localhost:8000/docs` لفحص API.
4. ثبّت Flutter وAndroid SDK، ثم من مجلد `mobile` نفّذ `flutter pub get` و`flutter run`.

لإنشاء APK بعد تثبيت أدوات Android:
`flutter build apk --release --dart-define=API_BASE_URL=http://YOUR_SERVER_IP:8000`

## حالة التحقق
تم التحقق من صياغة ملفات Python، واستيراد تطبيق FastAPI، واختبار نقطة الصحة ووجود المسارات الأساسية. لم يمكن بناء Flutter أو APK في بيئة العمل الحالية لعدم توفر Flutter وAndroid SDK.

## تنبيه أمني
هذه نسخة تطوير محلية. لا تنشر الخادم على الإنترنت قبل إضافة تسجيل الدخول والتحقق من ملكية المشروع والصلاحيات والنسخ الاحتياطي وتحديد معدل الطلبات.
